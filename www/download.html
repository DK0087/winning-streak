Android

Install the full app, with the nightly reminder.

Download WinningStreak.apk
  1. Tap Download WinningStreak.apk above, then open it.
  2. When Android says the file can't be installed, tap Settings and turn on Allow from this source (Install unknown apps) for your browser, then go back.
  3. Tap Install, open Winning Streak, and allow notifications.

Updates install right over the old app — same signing key, forever.
Or get it from GitHub Releases.

iPhone & any phone

Install the web app — works offline, no app store.

Open the web app
  1. iPhone (Safari): tap the ↑ Share button, then Add to Home Screen.
  2. Android (Chrome): tap ⋮ menu, then Add to Home screen / Install app.
Launch Winning Streak

Everything you enter — wins, goals, photos and your streak — stays on your phone and works offline. Switching phones? Use Back up on the home screen to save a file, and Restore it on the new phone.
